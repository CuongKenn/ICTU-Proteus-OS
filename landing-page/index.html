Ốc đảo Thông tin

Vận hành nhiều phần mềm rời rạc không liên thông, dẫn đến dữ liệu trùng lặp, thiếu chuẩn hóa và đứt gãy báo cáo quản trị.

Khung tiến hóa H-P-D-I — 4 không gian tích hợp

Chuyển giao năng lực điều hành tuần tự từ con người sang thuật toán tự động và trí tuệ nhân tạo có giám sát.

[H] Human

Môi trường làm việc số tích hợp

Đăng nhập một lần qua Keycloak SSO để truy cập toàn bộ không gian làm việc. Giao tiếp tập trung trên Mattermost và quản trị tri thức trên Outline Wiki.

Tự động hóa Quy trình Event-Driven

[D] Data

Nguồn sự thật duy nhất (Unified DB)

PostgreSQL kết hợp Row-Level Security bảo đảm cô lập dữ liệu đa thuê ước. Metabase cung cấp 17 bảng điều khiển trực quan theo thời gian thực.

PostgreSQL RLS Metabase BI Qdrant Vector

Mở rộng phân hệ nghiệp vụ chỉ với 1 thao tác

Kiến trúc Micro-Kernel kết hợp đặc tả manifest.yaml cho phép triển khai hoàn chỉnh 9 phân hệ chuyên ngành trong vòng 30 giây.

  • Tự động khởi tạo đồng bộ

    Tự động chạy schema PostgreSQL, bật RLS, nạp luồng n8n và khởi tạo báo cáo Metabase chỉ từ một file manifest.

  • Auto-Rollback & Cleanup Agent

    Cơ chế Compensating Transaction tự động dọn dẹp tài nguyên khi cài đặt gián đoạn, tránh để lại dữ liệu rác.

  • Giao tiếp liên phân hệ qua Redis Event Bus

    Kiến trúc hướng sự kiện decoupled: Nhân sự phát sự kiện, Tài chính tự động lắng nghe và xử lý đồng bộ.

  • Quản lý phiên bản & Migration

    Hỗ trợ nâng cấp phân hệ theo Semantic Versioning an toàn và không gián đoạn dịch vụ.

Triển khai từ Mã nguồn trong 3 bước

Yêu cầu hệ thống: Docker Engine ≥ 24.0, Docker Compose ≥ 2.20, RAM ≥ 8GB.

1

Tải mã nguồn

git clone https://github.com/CuongKenn/ICTU_Proteus-os.git
cd ICTU_Proteus-os
2

Cấu hình biến môi trường

cp deploy/.env.example deploy/.env
# Tùy chỉnh domain, SMTP, LLM...
3

Khởi chạy tự động

cd deploy
chmod +x setup.sh
./setup.sh

Sau ~2–3 phút khởi tạo: Launchpad tại localhost:3000 · API Docs tại localhost:8000/docs · Keycloak Admin tại localhost:8080
